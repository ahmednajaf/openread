# Native OpenRead

SwiftUI on iPhone/iPad. Kotlin + Jetpack Compose on Android. Kitten voices run on the phone, with no Mac helper.

These are developer previews, not store releases. **[Setup, supported features and build checks](../../docs/MOBILE.md)**

- `ios/`: checked-in Xcode project, reader and share extension; iOS 17+.
- `android/`: Android Studio project and Gradle wrapper; Android 8+, ARM64/x86_64.
- `shared/`: pinned model downloads, reading fixtures, sample text and attributed pronunciation source.

[Licences and notices](shared/NOTICES.txt) ship in both apps’ Settings. SDKs, model files, generated builds and signing keys stay out of Git.
