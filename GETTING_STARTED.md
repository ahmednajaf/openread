# OpenRead, without the technical bits

OpenRead reads webpages aloud with natural voices and highlights the words on the page. It works in **Safari and Chrome on Mac**. It is an early development build, not a signed App Store or Chrome Web Store download yet.

## 1. Put the folder somewhere permanent

Download the repository ZIP, unzip it, and move the whole **openread** folder into Documents. Keep the files together. If you move the folder later, load the extension from its new location again.

You do **not** need Node, Homebrew, Xcode, an API key, or an account for the folder installation.

## 2. Set up the voices once

Double-click **Set Up OpenRead.command** in the folder. A Terminal window will show progress. It installs OpenRead's private packages and downloads about **586 MB** of app/voice/alignment models. Kitten’s Kiki is the default voice; Kokoro is included as an alternative. It leaves your other Python projects alone.

If it says Python is missing, install **Python 3.13** using the macOS installer from [python.org](https://www.python.org/downloads/macos/). Choose a 3.13 release, not a newer Python series. Open the installer’s **Install Certificates.command** once, then double-click Set Up OpenRead.command again. OpenRead also accepts Python 3.11 and 3.12.

When it says **Ready**, setup is finished. Internet is needed for setup; the installed voices run locally afterward. Initial setup can take several minutes or longer on a slow connection. If a download fails, run setup again.

If macOS prevents a downloaded command file from opening, follow the file’s system-provided security prompt only after checking that you downloaded this repository intentionally. There is no need to disable Gatekeeper or change global security settings. If Finder says the file is not executable, the manual setup commands are in docs/DEVELOPMENT.md.

## 3. Start OpenRead

Double-click **Start OpenRead.command**. Leave its Terminal window open while listening. Your local library opens in the browser. You can minimize the Terminal window. Control-C stops the helper.

Start OpenRead again after restarting your Mac. If it is already running, the launcher opens the existing library. After updating OpenRead, run Set Up OpenRead.command once for new packages/models, stop the old helper with Control-C, then start it again.

## 4. Add it to your browser

### Chrome

1. Type `chrome://extensions` into Chrome’s address bar.
2. Turn on **Developer mode** at the top right.
3. Click **Load unpacked**.
4. Select the **extension** folder inside OpenRead. Select the folder itself, not a file inside it.
5. Click Chrome’s puzzle-piece icon, then pin **OpenRead**.
6. Open an article and click the book icon. Choose **Listen to page**.

The same source folder works directly in Chrome; you don't need to build anything. A separate distributable Chrome ZIP can also be generated by developers with `npm run chrome`.

Chrome may show a local-network access prompt when connecting to the helper. OpenRead connects to `127.0.0.1` on this computer for local voices. A website's own access request is separate from the extension's.

To update: replace the source files, click the reload arrow on OpenRead’s card at `chrome://extensions`, and refresh the article tab.

### Safari

1. In Safari, open **Settings → Developer → Add Temporary Extension…**.
2. Select the **extension** folder inside OpenRead.
3. Complete Safari/macOS’s unsigned-extension prompt if shown.
4. Enable OpenRead in **Settings → Extensions** for your Safari profile.
5. Open an article and click the book icon. Choose **Listen to page**.

Temporary extensions may need adding/enabling again after Safari restarts. A signed, permanent Safari app needs Apple distribution/signing; this folder install is the free development route. If your Safari version doesn't offer **Add Temporary Extension**, the Xcode wrapper instructions are in docs/DEVELOPMENT.md.

Safari supplies its own native glass for the toolbar popup. Device appearance is automatic. If Safari asks for one click on the webpage to authorize audio, click the temporary **Start listening** pill there.

## What you can do

- Listen in the original webpage, with word highlighting and optional follow-along scrolling.
- Choose a voice, set speed between **0.5× and 5×**, select text, paste text, or set a sleep timer in Reading options.
- Open **Reading options → Library & tools** for files, scans, bookmarks, local summaries, questions, audio overviews, and dictation.
- Use **Save this reading** to keep an article in your local library. Nothing automatically saves every webpage you visit.
- Import a PDF, Word `.docx`, EPUB, text, HTML, or a photo. Scan & Listen uses Apple's local Vision OCR on Mac, including image-only PDF pages. EPUBs must be DRM-free. Imports have size limits; split very large books into chapters.
- EPUB imports include a chapter picker and previous/next chapter controls. OpenRead uses the book’s contents list (EPUB 3 navigation or EPUB 2 NCX) in reading order, with headings as a fallback. Chapter jumps keep playback going if you are listening, or stay paused otherwise. Save the book to keep its chapters and reading position; library backups include them too. Reimport previously saved EPUBs to add chapter navigation. Editing the imported text removes its chapter navigation.
- Export a reading as a WAV audio file. Exports use the selected voice at natural speed; playback speed is adjustable in your audio player. Generating a long file takes time.
- Choose a file from your installed Google Drive, Dropbox, OneDrive, or iCloud **synced folder** in the file picker. OpenRead does not log into those providers or directly connect their APIs.

### WhatsApp Web

Open a conversation at **web.whatsapp.com**, then click OpenRead and **Listen to chat**. Chat mode reads the loaded text messages from oldest to newest and announces the sender; your own messages begin “You said”. In **Reading options**, you can turn off **Announce senders** or **Refresh loaded messages** after scrolling up to load older messages. Refresh also includes newly arrived messages; they never start playing automatically.

Chat text is processed by the same local voice helper. It is not saved to your library unless you choose **Save this reading**. Photos, stickers, voice notes, quoted repeats, timestamps and chat controls are skipped. Switching conversations or changing the message being read stops playback. WhatsApp's layout can change; if no messages are found, select the message text and use **Selected text** instead. This mode is for WhatsApp Web, not the desktop or phone apps.

## Featured voices

The main setup includes **Kitten TTS Mini 0.8**. Its eight voices are Bella, Jasper, Luna, Bruno, Rosie, Hugo, Kiki and Leo. Kiki, Rosie and Jasper appear first under **Featured · Kitten**; Kiki is the default. For an older OpenRead install, double-click **setup/Set Up More Voices.command**, then restart OpenRead and reload the extension.

The pack downloads about **82 MB**, plus **Whisper Base (~150 MB)** and its packages if not already installed. Kitten's code/weights are Apache-2.0 licensed. It runs on CPU and needs no account or API key.

Kokoro remains available as an alternative with direct model timing outputs and faster preparation. Kitten uses local Whisper to estimate word boundaries from its actual audio, which adds preparation time and can make highlighting less precise. Voice quality is subjective; try a preview before choosing one for a long reading. These are different voices from the similarly named Kokoro voices. This pack uses the Mini 0.8 model, not Kitten TTS 2, whose model license differs.

## Optional: summaries, questions and audio overviews

This is a separate one-time download of approximately **2.5 GB** plus the Ollama app. An Apple Silicon Mac with **at least 8 GB RAM** is a reasonable starting point; 16 GB gives more room to run a browser and several models together. Actual speed depends on your machine. Older/Intel Macs can be much slower. These are practical guidelines, not a hardware certification.

1. Install and open the free [Ollama app](https://ollama.com/download).
2. Double-click **setup/Set Up AI.command** in OpenRead’s folder.
3. Keep Ollama running. Open **Library & tools**.
4. Load a reading, open **Reading tools** (the sparkle icon), and choose **Summarize**, **Ask**, or **Discuss**.

This downloads **Qwen3 4B**, an Apache-2.0 model. OpenRead always calls the local Ollama address and this local model; it never selects a cloud model or asks for a paid key. Summaries cover the document in sections. Question answering retrieves relevant excerpts and shows them beneath the answer. It can miss relevant passages. Verify AI output against the original.

Audio overview generates a short two-host script, then **Make the audio** turns it into a playable/downloadable WAV using Kitten Kiki and Jasper. This is a generated interpretation, not a verbatim audiobook.

## Dictation and meeting notes

1. Whisper Base (~150 MB) is included in the current voice setup for word alignment, so dictation uses that same local model. Older installs can double-click **setup/Set Up Dictation.command**.
2. In **Library & tools → Reading tools → Dictate**, choose **Start recording** or **Import audio**.
3. Your browser asks for microphone access only when you start recording. Stop recording to transcribe it on this computer.
4. Use **Copy transcript** to paste into any app, or **Use transcript as reading** to listen to it.
5. With optional AI set up too, **Create meeting notes** extracts decisions and action items from the transcript. Speakers are not automatically identified.

**Record question** in the question tab uses the same local dictation model, then asks the local AI about your reading. **Read answer aloud** speaks its answer. This is a reading assistant, not an always-listening system assistant.

In-browser recordings stop automatically after five minutes (voice questions: 90 seconds). Imported recordings can be up to one hour / 20 MB. Transcripts are imperfect, especially with background noise, accents, overlapping speech, or long silences.

## Your data and storage

Unsaved readings, uploads, recordings and generated audio stay in memory while a task runs. Completed task results expire after 15 minutes if not collected. Choose **Save to library** to persist a document. Saved documents, bookmarks and reading position live in `.local/library.sqlite3` inside the OpenRead folder. Local browser storage remembers voice and speed. Use **Delete** to remove a library entry or download a backup with the library’s down-arrow button. Backups contain your document text; store them accordingly.

The models occupy disk space locally: `.local/models` for voices, `.local/whisper-base` for dictation, and Ollama’s model storage for Qwen. Setup downloads contact their official package/model hosts. Normal reading and AI processing do not send your documents or recordings to a cloud service. Your browser, synced-folder provider, or OS may independently have its own services enabled.

## If something isn't working

| What you see | What to do |
| --- | --- |
| Natural voices aren't connected | Start OpenRead.command and leave its window open. Restart the helper after source updates. |
| New controls missing after an update | Reload the extension in browser settings, then refresh the article. |
| A voice cannot align or generate a passage | Try another voice. Short headings use approximate timing if Whisper misses them; update OpenRead and restart the helper if an older version reports this as a connection error. |
| AI setup needed | Start Ollama and run setup/Set Up AI.command. Open Setup & privacy in the workspace to check readiness. |
| Dictation setup needed | Run setup/Set Up Dictation.command. Microphone recording also needs your browser permission. |
| Scanned PDF won't import | Scan & Listen currently needs macOS. Try a smaller section: 20 scanned pages maximum. |
| Voice sounds wrong for a language | Choose the matching language voice. English is the strongest; additional languages are experimental. Japanese and Mandarin are not exposed in this build. |
| It reads a menu or misses text | Extraction is heuristic. Select the text you want, or paste it into the workspace. |
| Browser settings/PDF viewer cannot be read | Import the PDF in Library & tools instead. Browser-internal pages are protected. |
| Safari Reader hides word highlights | Highlights belong to the original webpage. Safari’s protected Reader view is outside that page. |

For exact coverage and current limits, see [docs/FEATURES.md](docs/FEATURES.md).

## Updating to the new reading app

Download the updated repository and keep your existing `.local/` folder if you are updating in place. Stop the helper with Control-C, then double-click **Start OpenRead.command** and refresh the library page. Saved readings, bookmarks and progress keep the same storage format. Reload the extension in Safari/Chrome settings and refresh article tabs to update its controls.

The library opens with a glass landing page. Choose **Try with The Odyssey**, **Bring your own text**, or **Library**. The floating player holds voice, playback and speed; the sparkle icon opens summaries, questions, conversations and dictation. The three-dot menu contains bookmarks, exports, reading options and setup/privacy. Library backup/restore is inside **Library**. Appearance follows the device.
