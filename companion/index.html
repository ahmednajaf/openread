Everything happens here.

Reading needs the local voice helper. AI and dictation are optional downloads. Documents stay in memory until you choose Save. Saved readings, bookmarks and progress live in .local/library.sqlite3. Delete them here or remove that file. No account, analytics or cloud AI.

Checking your local tools…

On Mac, double-click Set Up OpenRead.command first. For summaries, chat and podcasts, install Ollama from ollama.com, then double-click Set Up AI.command (about 2.5 GB). For eight more English voices, double-click Set Up More Voices.command (included in current setup; 82 MB plus local alignment for older installs). For dictation, double-click Set Up Dictation.command (about 150 MB plus packages). Close and reopen this panel to check again.

Scan & Listen uses macOS Vision. Other systems can import text PDFs and documents. The helper must stay running. See GETTING_STARTED.md in the downloaded folder for browser installation.
